# Customer Churn Prediction: Logistic Regression vs Decision Tree

## Project Overview
This project compares Logistic Regression and Decision Tree models for predicting customer churn.

## Dataset
Telco Customer Churn Dataset

## Preprocessing
- Missing value handling
- One-hot encoding
- Standardization (for Logistic Regression)

## Models
- Logistic Regression
- Decision Tree Classifier

## Results

| Model | Accuracy |
|------|--------|
| Logistic Regression | 0.82 |
| Decision Tree | 0.79 |

## Key Insight
Logistic Regression performed better due to linear relationships in data and better handling of class imbalance.
